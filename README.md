# SampadHelp

ابزارهای ساده برای آمادگی آزمون و مطالعه:

- درصدگیر آزمون با انتخاب نمره منفی
- تایمر شمارش معکوس برای شبیه‌سازی آزمون
- پومودورو با زمان‌های قابل تنظیم
- تاریخچه درصدها و زمان تمرکز
- روتین روزانه
- محاسبه میانگین زمان هر تست
- ذخیره محلی اطلاعات در مرورگر و خروجی JSON

## اجرا

این پروژه یک سایت استاتیک است و به بک‌اند نیاز ندارد. کافی است GitHub Pages را برای شاخه `main` فعال کنی.

## حریم خصوصی

اطلاعات عملکرد و تنظیمات در `localStorage` مرورگر ذخیره می‌شود و این پروژه برای کارکرد اصلی خود اطلاعاتی به سرور ارسال نمی‌کند.
